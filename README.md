
# Learning-Fih

Egy Android telefonokra készített dolgozat naptár a diákok számára.
## Funkciók

- Saját naptár saját órarenddel
- Dolgozat mentése
- Dolgozat elötti figyelmeztető értesítés
- Teljesen lokálisan működik



## Telepítés

Ezen a <a href="https://github.com/FatFih/Learning-Fih/releases" target="_blank">linken</a> keresztul töltse le a legújabb verzióját az applikációnak (a .apk file-t).

Miután le töltött, nyomjon rá az eszközén a .apk file-ra és folytassa a telepítő instrukcióját.
